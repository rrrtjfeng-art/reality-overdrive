# Reality Overdrive — 现实超载

An immersive mobile-first daily challenge universe combining cinematic Chinese storytelling, manifestation-inspired visualization, high-difficulty language quests, random virtual multiplier rewards, and grounded wealth-building experiments.

## Features
- Morning, midday, and night rituals
- Random story scenes and surprise events
- Virtual XP, levels, multipliers, and a three-session bonus
- Language reasoning challenge that distinguishes feelings from evidence
- Practical, low-cost wealth experiment prompt
- Local browser persistence via `localStorage`
- No dependencies, build tools, API keys, or paid services

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## GitHub Pages
Open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages can publish static files from a repository. See the [official documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Notes
All XP and multiplier rewards are fictional in-app game rewards, not real money or investment returns. Visualization is an imaginative exercise, not a guarantee of external outcomes.
